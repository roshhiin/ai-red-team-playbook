# ai-red-team-playbook
The AI Red Team Playbook

Mission: To document real-world AI attack vectors and map them to runtime defenses.

As an aspiring AI Security PM, I believe you cannot build a shield without understanding the sword. This repository is my research into how hackers break AI agents (Red Teaming) and how we stop them (Blue Teaming).

My Current Focus:

· Prompt Injection (Direct & Indirect)
· OWASP Top 10 for LLMs
· Agentic AI Runtime Security

Mapped to the ACS Guardian Project.
